# steam-link

Add a steam db link to store.steampowered.com so you don't have to go finding it

Thank you

## Installation

1. Download zip from [Github](https://github.com/jeegnathebug/steam-link/archive/refs/heads/main.zip)
2. Unzip contents and move folder to wherever you keep chrome extensions
3. In Chrome, go to `chrome://extensions/`
4. Click "Load unpacked"
5. Select the unzipped folder

Note: SteamDB link will open in a new tab
